# ADR-0006. Позиционирование «инструмент технического анализа» и новый стиль сайта

Статус: принято владельцем. Дата: 2026-10-30.

## Контекст

Сайт строился вокруг сигналов на H4 (план, 1.1). Владелец решил продавать продукт как **инструмент технического
анализа** — собственный график уровня TradingView с автоматической разметкой и пошаговым разбором по таймфреймам.
Сигналы возвращаются позже, отдельной задачей. Прежний вид сайта владелец счёл «дешёвым и шаблонным»; из 21 реального
сайта-образца он выбрал Robinhood, Nansen и Hyblock.

## Варианты

1. Оставить сигналы главным продуктом, только перекрасить сайт. Минус: не совпадает с решением владельца.
2. Отдельный сайт для графика. Минус: две кодовые базы, вдвое больше работы.
3. **Тот же сайт, график — главный продукт; сигналы спрятаны из меню и с главной, код и данные сохраняются.**

## Решение

Вариант 3.

- **Меню кабинета:** График, Скринер, Алерты (+ Админка), под ними «Мои монеты» (вотчлист с ценами). Тариф,
  настройки и поддержка — в блоке аккаунта. Сигналы, статистика, журнал и калькулятор убраны из меню, страницы
  остаются по прямым ссылкам. После входа и регистрации пользователь попадает на график (`/chart`).
- **Слои графика по умолчанию:** структура, зоны, поддержка/сопротивление, карта ликвидаций, фигуры; слой сигналов
  выключен (`LAYERS_VERSION` = 4).
- **Главная** — про теханализ: заголовок «Технический анализ. Без рутины.», настоящие скриншоты терминала,
  индикаторы, инструменты рисования, автоматическая разметка, мультичарт, телефон, тарифы. Числа на главной берутся
  из `apps/web/src/lib/capabilities.ts` и сверяются с кодом графика тестом.
- **Стиль** (заменяет палитру и шрифты плана 5.3–5.4):
  - тёмная тема по умолчанию: фон `#050607`, поверхность `#0B0E10`, граница `#1D2327`, текст `#EEF1F0`;
  - один салатовый акцент `#C6F432` для действий (кнопки с тёмным текстом `#0A0C05`); в светлой теме ссылки
    тёмно-зелёные `#3F6212`, кнопки остаются салатовыми;
  - рост/падение: `#22C58B` / `#F2555C` (тёмная), `#0A7F55` / `#C8283A` (светлая);
  - шрифты: Manrope (интерфейс), Source Serif 4 (крупные заголовки маркетинговых страниц), IBM Plex Mono (цифры);
  - кнопки на маркетинговых страницах — «таблетки»; бирюзовое свечение (`--glow`) только под скриншотом продукта.
- **Знак:** салатовое кольцо с точкой («солнце» Sol и метка цены).

## Последствия

- Проще объяснять ценность: человек сразу видит рабочий терминал, а не рекламу.
- Требования плана 5.2 и 2A.10.6 к текстам остаются: без обещаний доходности, без «ИИ предсказывает».
- Онбординг по профилю риска больше не показывается после регистрации; страница `/onboarding` доступна по ссылке.
- Следующие задачи этого направления: панель «Разбор» (анализ сверху вниз W1 → D1 → H4 → H1 → 15m),
  календарь событий США, скринер «где совпали таймфреймы». Логику «Разбора» владелец проверяет на примерах до выпуска
  (план 10.4).
- Пересмотреть, когда вернёмся к сигналам: место сигналов в меню и на главной.
