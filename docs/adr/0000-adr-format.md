# ADR-0000. Формат записей архитектурных решений

Статус: принято. Дата: 2026-10-25.

Каждое ключевое техническое решение записывается в `docs/adr/NNNN-короткое-название.md` со структурой:
**Контекст** (что решаем и почему сейчас), **Варианты** (с плюсами и минусами), **Решение**, **Последствия**
(что это упрощает, что усложняет, что пересмотреть позже). Черновик пишет Fable 5, утверждает человек (план, 10.1).

Запланированные ADR из плана: 0001 — движок графика (LWC vs KLineChart, этап 2B), 0002 — рендер графика в React Native (этап 4B).
