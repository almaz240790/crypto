# ADR 0001. Дизайн-система web: CSS-токены и модули, без Tailwind и Storybook

Дата: 2026-10-25. Статус: принято. Задача плана: 2.6.

## Контекст

Раздел 5 плана требует одну палитру, шрифты IBM Plex, радиус 2–4px, плотные таблицы и ESLint-запрет
произвольных цветов. Нужен способ, при котором все экраны собираются только из токенов и компонентов.

## Решение

- Токены — CSS-переменные в `apps/web/src/styles/tokens.css`; светлая тема по умолчанию, тёмная через
  `[data-theme="dark"]` и `prefers-color-scheme`. Это единственный файл, где разрешены литералы цветов.
- Стили компонентов — CSS Modules, без Tailwind: utility-классы с произвольными значениями обходят запрет цветов.
- Проверка `npm run lint:colors` (`scripts/check-colors.mjs`) ищет `#hex`, `rgb()/hsl()` и именованные цвета
  в `src/**` и входит в `npm run lint` и CI. Это замена «ESLint-правила» из плана: ESLint не видит CSS.
- Витрина компонентов — страница `/ui` в самом приложении вместо Storybook: меньше зависимостей, та же
  проверка глазами в обеих темах и на мобильном.
- Шрифты через `next/font/google` (self-hosted при сборке), цифры — `tabular-nums`.

## Последствия

Любой новый цвет добавляется только в токены. Компоненты страниц 2.7–2.12 импортируются из
`@/components/ui`. Storybook можно добавить позже, если появится отдельный дизайнер.
