# Бэктест trend-ob-retest@1.1.0 на 60 парах — проверка п. 2 решения walk-forward

Дата: 25.10.2026. Прогоны сохранены в БД (`backtest_runs`), видны на `/stats` → «Бэктест».
Данные: свечи H4/D1/W1 2022-06-01 — 2026-10-25, вход рыночный, комиссия 0.05 % и проскальзывание
0.03 % за сторону. Деривативы (funding/OI/long-short) в истории были загружены только для 20 пар MVP;
для 40 новых пар на момент прогона истории деривативов почти не было — их фильтры работали
«нейтрально». Загрузка истории деривативов по 60 парам запущена, прогон будет повторён.

## Выводы (не решение — решение за заказчиком, план 10.4)

1. Преимущество версии 1.1, показанное на 20 парах, **не переносится** на расширенный список как есть.
   Это не доказывает, что список расширять нельзя, но доказывает, что делать это без отдельной проверки нельзя.
2. Лонги убыточны и на 20, и на 60 парах (−2.8 R и −24.9 R). Вопрос про лонги (п. 3 решения walk-forward)
   становится главным: вариант «только шорты» или отдельные пороги для лонгов надо проверить на обоих списках.
3. Часть просадки на новых парах может объясняться отсутствием истории деривативов. После догрузки
   прогон #5 будет повторён; если итог по 39 новым парам останется отрицательным — расширение откладывается.
4. Форвард-тест сейчас идёт по 59 инструментам. Для сбора данных это полезно; но кандидат в `live`
   на сегодня — **1.1 только на 20 парах MVP**. Переключение инструментов для live — через новую запись
   версии стратегии (план 2.9), не правкой списка.

## Что дальше
- Повторить прогон на 60 парах после загрузки деривативов (сервис `deriv-loader`, список extended).
- Эксперимент «лонги»: (а) запрет лонгов, (б) лонги только при bias W1 = up и градации A — на IS/OOS, оба списка.
- Пересмотреть компонент скоринга «sweep перед входом» (+15): по #5 градация не ранжирует исходы.

## Дополнение 2026-10-26: повтор на 60 парах с полной историей деривативов (прогон #8)

Загрузчик `deriv-loader` догрузил funding / OI / long-short с 2022-01-01 по всем 60 парам
(для новых пар раньше было только 2 дня). Прогон #8 — та же версия 1.1, тот же список и период, что #5.

Деривативы изменили 7 сделок из 350 и ничего не изменили в итоге. Гипотеза п. 3 выводов («просадка
на новых парах объясняется отсутствием истории деривативов») **не подтвердилась**.

Следствие по п. 3: расширение списка до 60 пар для версии 1.1 откладывается. Даже без лонгов 39 новых
пар дают −2.4 R при PF 0.97 — они не добавляют преимущества, только сделки и просадку. Кандидат в live
остаётся прежним: 1.1 (или 1.2 «только шорты» после решения) на 20 парах MVP. Если список и расширять,
то отбором пар по отдельной проверке, а не всем блоком; форвард по 59 инструментам при этом полезен
как сбор данных.

Следом идут прогоны 1.2 и «1.2 без бонуса за снятие» на тех же 60 парах (одна цепочка на сервисе
backtest) — результаты будут дописаны в отчёты по лонгам и скорингу.
